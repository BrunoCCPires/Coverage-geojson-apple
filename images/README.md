# Images Directory

This directory contains visual documentation for the Apple App Store routing coverage implementation.

## Expected Images

1. **app-store-connect-navigation.png** - Screenshot showing how to navigate to App Information in App Store Connect
2. **routing-coverage-section.png** - Screenshot showing the Routing Coverage section where Coverage.geojson should be uploaded
3. **brazil-coverage-map.png** - Visual representation of the GeoJSON coverage area for Brazil

## Notes

- Images should be in PNG format for best quality
- Screenshots should be taken at standard resolution (1920x1080 or similar)
- Include clear annotations or highlights where necessary
- All images should be properly optimized for web viewing
