# Covarage-geojson-apple
Arquivo de covarage de todo território Brasileiro. 

## English (EN-US)

### Apple App Store Routing Coverage File for Brazil

This repository provides a solution for the Apple App Store error ITMS-90117 for navigation applications targeting the Brazilian market.

#### Purpose
- Resolve ITMS-90117 error during App Store submission
- Provide a pre-built GeoJSON coverage file for Brazil
- Simplify the routing app coverage requirement

#### How to Use
1. Download the `Coverage.geojson` file
2. Go to App Store Connect
3. Navigate to your app's App Information
4. Find the "Routing Coverage" section
5. Upload the downloaded `Coverage.geojson`

![App Store Connect Navigation](images/app-store-connect-navigation.png)

![Routing Coverage Section](images/routing-coverage-section.png)

#### Technical Details
- File Format: GeoJSON
- Coverage: Entire Brazilian Territory
- Compatibility: iOS Navigation Apps
